This repository currently contains a documentation-only Unity package for testing Unity Package Catalog. It adds no scripts, game assets, or project settings.

- Package ID: `com.carlos.unity-agents-template`
- Version: `0.1.0`
- Display name: **Unity Agents Template (Test)**

The package is at the repository root, so its Git installation URL does not need a `?path=` suffix. Commit and push these files before testing installation from GitHub. A release tag is optional; create one if you want to pin the catalogue entry to a fixed revision.

In your private catalogue, use this package ID and version, along with this repository's Git URL. After installing in CatalogTest, select the package in Package Manager and locate this README to confirm that its content arrived. Remove the package when finished.
